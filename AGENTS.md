# Execução local

Por solicitação do usuário, este projeto deve ser utilizado na própria máquina do aluno. Não publicar, implantar ou enviar alterações para ChatGPT Sites ou outra hospedagem externa sem um novo pedido explícito do usuário. A configuração de hospedagem foi removida. Distribuir o código pelo GitHub não autoriza hospedar a aplicação.

Manter a aplicação sem dependências de rede para funcionar e preservar o aviso de projeto acadêmico independente, destinado aos alunos da CESAR School, sem finalidade comercial e sem caráter oficial.
